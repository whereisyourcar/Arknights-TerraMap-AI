# Arknights TerraMap（AI制作版）

**把泰拉的地图、主线行迹和活动故事，放进同一本可交互的地理档案。**

一个面向《明日方舟》同好的非官方网页项目，由 AI 辅助完成开发、美术与资料整理。欢迎边看剧情边翻地图，也欢迎带着游戏原文来挑错、补全！

## 在这里可以看到什么

- **泰拉大地图**：地理绘卷与官方地图对照，点击国家、地区和城邦查看介绍、人物、干员及资料来源。
- **势力领袖档案**：左侧按国家、地区与组织切换，人物按势力分组，身份地位醒目标注；地图头像直接打开站内介绍。
- **干员来自哪里与干员种族**：438 个干员条目，左侧按出身地或种族筛选，支持全体姓名搜索与站内介绍；覆盖《时间啊，向前！》版本，全部头像保存在本项目。
- **主线剧情行迹**：覆盖第0—17章的72个关键节点。跟随势力和小队的位置变化，使用章节时间轴、节点播放与连续地图切换浏览故事。
- **按归属找活动**：72 个可回顾活动、13 条游戏乐章及补充目录，按国家、地区、组织和人物搜索筛选。每篇含故事概要、两句导读、可点人物头像、首开日期与剧情篇数，并可跳转同乐章前后篇。想补巴别塔，就看《方舟》；想了解谢拉格，就从《风雪过境》一路看到《银心湖列车》《雪山降临1101》。
- **每条资料有出处**：优先游戏官方资料，交叉核对BWIKI等百科。活动剧情回顾与常驻关卡分开标注，地图相对方位与未确定的位置也分别说明。
- **桌面和手机都能用**：深蓝灰与金色界面、角色头像、地点说明和可展开的来源。
- **留言板**：10 个精细绘制的 Q 版同人头像，选择时可查看大图预览；昵称加留言，支持 Unicode 文字与表情，刷新和服务重启后保留留言。
- **三句人物小传**：全部可点击人物入口共用带来源的小传，合并本名／代号，明确历史阶段和档案中的可能未来。
- **四种语言**：右上角切换简体中文、繁體中文、English、日本語；包括菜单、地图文字、故事和人物档案，支持本地化姓名搜索。访客留言保留原文。
- **匿名访客计数**：网页角落显示累计访客及访问次数，服务端持久保存；不采集IP或浏览轨迹。

## 本地运行

需要 Node.js 22 或更新的受支持版本。无第三方运行依赖。

```bash
git clone https://github.com/whereisyourcar/Arknights-TerraMap-AI.git
cd Arknights-TerraMap-AI
npm start
```

打开 http://127.0.0.1:4185/ 。运行全部检查：

```bash
npm run check
```

## 自行部署与访客计数

当前公网部署使用独立 Docker Compose 项目，映射 `30020:4185`，不占用同服务器 TGMap 的端口或容器：

```bash
docker compose -f deploy/compose.yaml up -d --build
```

打开 `http://服务器IP:30020/`；如果端口已被占用，请修改 `deploy/compose.yaml` 中映射的左侧端口。统计保存在独立的 `visitor-data` 数据卷，更新与重启会保留；不要使用 `down -v` 删除该数据卷。

直接运行 Node 服务时默认仅监听本机，`HOST` 可调整监听地址，也可使用 Nginx 反向代理。`deploy/` 提供 systemd 服务与 `/terramap/` 路径代理模板；部署到其他路径时仍需保留尾部斜线。`PORT` 控制本地监听端口，`VISITOR_DATA_FILE` 指定统计文件路径。使用HTTPS时设置 `PUBLIC_ORIGIN=https://你的域名`，访客Cookie将带Secure属性。

统计默认保存到 `var/visitors.json`，已从Git排除。服务器应使用独立持久目录（模板为`/var/lib/terramap`），更新代码时不要覆盖它。当前实现用于单进程服务；多实例部署需先改用共享数据库。

“访客”按匿名第一方Cookie对应的浏览器计数；清除Cookie、无痕模式和更换设备可能重复计数，不等于去重后的自然人。“访问”按同一浏览器30分钟无访问后重新进入计数。Cookie用于去重，数据文件仅保留匿名标识摘要、最后访问时间和汇总；静态镜像若不运行此服务会显示统计暂不可用。

### 留言数据

默认保存到 `var/guestbook.json`；通过 `GUESTBOOK_DATA_FILE` 可指定位置。Docker 沿用原有持久卷 `/app/var`，systemd 模板保存到 `/var/lib/terramap/guestbook.json`。数据文件不进入 Git，更新代码时不得覆盖；备份时同时保存留言与访客统计。

留言公开展示昵称、选定头像、正文及时间，不保存 IP。接口限定本地头像 ID、昵称 1—24 个 Unicode 字符、正文 1—1000 个字符，同源 JSON 请求，超长请求和跨站提交被拒绝；访客文字以纯文本显示。每个连接地址每 10 分钟最多提交 5 次，限流键为仅在内存中的临时摘要。当前为单进程文件存储。反向代理后的连接可能共享限流额度；如需按真实客户端限流，应在可信代理层配置，不接受客户端随意伪造的转发头。静态托管不具备留言写入服务。

### 维护译文

`node scripts/extract-i18n.mjs` 提取显示文本，`dist/locales/manual-*.json` 保存分批审核的英日译文及官方名称。用安装了 `opencc-python-reimplemented` 的 Python 运行 `scripts/build-locales.py`，构建会拒绝遗漏译文；`npm run audit:i18n` 检查覆盖率、插值变量及异常标记。语言文件随仓库发布，网页运行不需要 Python 或翻译模型。资料新增后须重新生成、校对并在浏览器检查动态弹窗。
